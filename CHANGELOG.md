## [Unreleased]

### Added
- Initial release of Ivy.Ripgrep
- Automatic binary provisioning for Windows, macOS, and Linux
- Support for x64, x86, ARM, and ARM64 architectures
- Streaming and buffered search APIs
- JSON output parsing for robust results
- Rich options model mapping to ripgrep flags
- Platform detection and RID mapping
- Binary download with checksum verification
- Cache management for downloaded binaries
- Integration with GitHub API for binary downloads
- Support for GITHUB_TOKEN authentication
- Comprehensive unit and integration tests
- Sample console application
- GitHub Actions CI/CD pipeline
